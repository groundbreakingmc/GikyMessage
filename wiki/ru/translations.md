# Переводы

[English](../translations.md) · **Русский** · [← Документация](README.md)

`lang:` показывает [сегмент](segments.md) на языке игры каждого игрока. Сервер отправляет ключ
перевода, а игра каждого игрока ищет его на том языке, на котором он играет:

```text
&7Вы нашли [&bАлмаз](lang:item.minecraft.diamond)&7!
```

![Одно сообщение у игрока с русским и с английским языком игры: Алмаз и
Diamond](../images/ru/lang-intro.svg)

## Откуда берутся ключи

- **Ключи самой игры** есть у всех предметов, блоков, мобов и эффектов:
  `item.minecraft.diamond_sword`, `block.minecraft.chest`, `entity.minecraft.creeper`. Все они
  перечислены в английском языковом файле внутри jar игры, `assets/minecraft/lang/en_us.json`.
- **Свои ключи** берутся из серверного ресурспака — по [языковому
  файлу](https://minecraft.wiki/w/Resource_pack#Language) на каждый язык:

`assets/myserver/lang/ru_ru.json`
```json
{ "myserver.welcome": "Добро пожаловать на сервер!" }
```

`assets/myserver/lang/en_us.json`
```json
{ "myserver.welcome": "Welcome to the server!" }
```

Затем используйте ключ в сообщении:

```text
[&aДобро пожаловать на SkyCraft!](lang:myserver.welcome)
```

![С ресурспаком каждый игрок видит перевод на своём языке, без ресурспака — текст из
скобок](../images/ru/lang-fallback.svg)

## Текст в скобках — запасной

Игроки, чья игра не знает ключа — например, потому что они отказались от ресурспака, — видят текст в
скобках, как в последней строке выше. Пишите его на основном языке сервера. [Запасной
текст](https://minecraft.wiki/w/Text_component_format#Translated_Text) показывает Minecraft 1.19.4 и
новее; более старые версии покажут сам ключ.

## Ключи с плейсхолдерами

Ключ можно собрать из плейсхолдеров, и тогда одна строка покрывает много переводов:

```text
&7Ранг: [&6{rank}](lang:myserver.rank.{rank})
```

При `{rank}` = `vip` игра ищет `myserver.rank.vip`, а у кого его нет, увидят `vip`.

## Полезно знать

- Перевод берёт стиль сегмента целиком: пишите `[&6VIP](lang:…)` или `&6[VIP](lang:…)`. Цвета
  посреди текста, как в `[V&cIP](lang:…)`, теряются.
- Сегмент показывает что-то одно. Если у него несколько из `head:`, `sprite:`, `lang:` и
  `gradient:`, работает только первое по этому списку, поэтому у переведённого сегмента не бывает
  градиента. `color:` и `style:` работают вместе с `lang:` как обычно.
- Если ключ пустой, например из-за пустого плейсхолдера, сегмент остаётся обычным текстом.

> [!NOTE]
> Переводам нужен Adventure 4.13 или новее на сервере, иначе сообщение не загрузится — ошибка скажет
> об этом.

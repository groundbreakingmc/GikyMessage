# Документация GikyMessage

[English](../README.md) · **Русский** · [← К проекту](../../README_RU.md)

GikyMessage превращает короткие строки вроде `[&a&nСпавн](run:/spawn)` в компоненты чата Minecraft.
В документации две части: **формат** — для всех, кто пишет сообщения, и **Java API** — для
разработчиков плагинов.

## С чего начать

- **[Быстрый старт](quick-start.md)** — первое цветное сообщение с кнопкой за пять минут.
- **[Шпаргалка](cheatsheet.md)** — весь формат на одной странице.
- **[llms.txt](../../llms.txt)** — весь формат одним файлом для ИИ-ассистентов, с правилами перехода
  с MiniMessage и `&`-кодов.

## Формат

| Страница | О чём |
|---|---|
| [Цвета и стили](colors.md) | `&a`, HEX-цвета вроде `&#ff8800`, жирный и курсив, тень текста |
| [Плейсхолдеры](placeholders.md) | `{player}` и другие значения, которые плагин подставляет при отправке |
| [Сегменты](segments.md) | Части, которые реагируют на мышь: `[текст](run:/spawn, show:подсказка)`, головы игроков, шрифты |
| [Градиенты](gradients.md) | Плавные переходы цвета и бегущие градиенты |
| [Условия](conditions.md) | Часть сообщения только при нужном значении: теги кланов, ранги, статус «в сети» |
| [Переводы](translations.md) | Текст на языке игры каждого игрока |
| [Преобразования](transforms.md) | `1234567` → `1.2M`, ВЕРХНИЙ РЕГИСТР, ꜱᴍᴀʟʟ ᴄᴀᴘꜱ, ограничение длины |
| [Экранирование](escapes.md) | `[`, `{` и `\` как обычный текст, переносы строк, кавычки в YAML |
